# FreeMindAgain

Минимальный редактор карт мыслей на HTML, CSS и JavaScript. Работает без сборки, сервера приложений, внешних библиотек и сетевых запросов.

## Запуск

Откройте `index.html` в современном браузере. Для стабильного автосохранения рекомендуется запуск через HTTP из каталога репозитория:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

## Возможности

- Новая карта, дочерние и соседние узлы, изменение названия и заметки через карточку.
- Двойной щелчок по группе — сворачивание/раскрытие; по листу — открыть карточку. F2 и карточка позволяют переименовать любой узел.
- Перетаскивание узла переносит всю его ветку, включая скрытых потомков.
- Перетаскивание фона, масштабирование колесом, вписывание карты.
- Сворачивание веток и удаление ветки с подтверждением; корень удалить нельзя.
- Отмена и повтор последних 100 изменений, включая перемещения, импорт и создание карты.
- Автосохранение последней карты в localStorage; ошибка сохранения отображается в карточке.
- Экспорт и импорт JSON: полное дерево, названия, заметки, статусы, координаты, цвета и свёрнутые ветки. Импорт проверяет версию, уникальность идентификаторов, ссылки и отсутствие циклов до замены текущей карты.

Специальные клавиши редактора: F2 — переименование выбранного узла, F3 — показать/скрыть карточку; +/Insert — добавить дочерний узел, −/Delete — удалить ветку с подтверждением. Tab используется для обычного перемещения фокуса, а Enter больше не создаёт узлы. В полях диалога Enter подтверждает ввод. Название и заметка в карточке сохраняются кнопкой «Применить». Справка по командам открывается кнопкой «?» в левом нижнем углу.

JSON — собственный формат FreeMindAgain версии 1. Формат FreeMind `.mm` и совместное редактирование пока не поддерживаются. Начальная раскладка простая; положение веток можно корректировать вручную. Поддерживаются файлы до 10 МБ и до 5000 узлов; это ограничение импорта, не гарантия производительности больших карт. Автосохранение привязано к браузеру и адресу страницы, поэтому для переноса или резервной копии используйте JSON.

```sh
node tests/model.test.cjs
# При запущенном локальном HTTP-сервере; нужны Python Playwright и Chromium:
python3 tests/browser_smoke.py
```

Тест браузера проверяет редактирование, заметки, перемещение ветки, отмену, сворачивание, удаление, скачивание и импорт JSON, восстановление после перезагрузки и ширину мобильного экрана.

## Ориентиры

Оформление и взаимодействия вдохновлены FreeMind и [ideev/pg_settings_map](https://github.com/ideev/pg_settings_map): кривые связи, цветовые ветки, перенос дочерних узлов вместе с родителем и боковая карточка. Реализация редактора и модель документа написаны отдельно; PostgreSQL-специфичные данные и генератор не используются.

## Открытие из чата

`FreeMindAgain.html` и `index.html` — одинаковые автономные страницы версии 0.1.15 со встроенными стилями и JavaScript. Каждая не зависит от загрузки соседних файлов. После изменений исходников пересоберите её:

```sh
python3 tools/build_standalone.py
```

Кнопки редактирования работают без отправки HTML-форм, в том числе в ограниченном просмотрщике. Регрессионная проверка воспроизводит iframe с запретом `allow-forms` и проверяет названия, комментарии, закрытие диалога, отмену и восстановление:

```sh
python3 tests/preview_smoke.py
```


При переносе группы через корень все её потомки, включая свёрнутые, переходят на соответствующую сторону: слева их правые края выровнены относительно родителя, справа — левые. Вертикальные координаты сохраняются. Перемещение и перестройка входят в одно действие отмены.

Оба HTML-файла содержат весь код и стили. Для использования достаточно **одного любого HTML-файла**. `app.js`, `model.js`, `style.css` и `tools/page.template.html` нужны только для разработки и пересборки, а не для открытия страницы.

Проверка взаимодействий с группами: `python3 tests/branches_smoke.py` (при запущенном HTTP-сервере).

## Имя JSON-файла

Перед каждым скачиванием открывается окно подтверждения имени. Для новой карты предлагается название корня с расширением `.json`; затем — последнее подтверждённое имя. Оно сохраняется в поле `fileName` самого документа и в локальной копии карты. При открытии старого JSON без этого поля используется имя выбранного файла. Отмена окна не меняет запомненное имя. Новая карта получает собственное имя по умолчанию.

В localStorage хранится один текущий документ: открытие другой карты или создание новой заменяет локальную копию. После перезагрузки восстанавливается последняя карта и её имя файла. Это хранилище привязано к браузеру и origin страницы.

Проверка: `python3 tests/save_smoke.py`.

## Прямая запись в файл (0.1.6)

В поддерживаемом браузере (Chrome/Edge, безопасный контекст — HTTPS или localhost) «Сохранить как…» открывает системный выбор папки и файла. «Сохранить» после подтверждения обновляет выбранный файл через File System Access API, без скачивания очередной копии. Изменение имени в окне сохранения также запускает выбор нового файла.

«Открыть JSON» использует системный выбор файла, если доступен; после такого открытия изменения можно записывать в исходный файл. Браузер может дополнительно запросить разрешение на запись. Отмена выбора не запускает скачивание и не меняет привязку к файлу. Ошибка записи остаётся в окне, откуда можно повторить операцию или нажать «Скачать копию».

Если API отсутствует, используется прежнее скачивание с подтверждением имени. Если просмотрщик блокирует API, ошибка объясняет причину и доступно «Скачать копию». Страница не может принудительно выбрать папку Downloads или управлять нумерацией копий при скачивании.

Имя и последняя карта сохраняются в localStorage, а разрешение/ссылка на локальный файл — только до закрытия или перезагрузки страницы. После перезагрузки файл нужно выбрать снова. Создание/открытие другой карты и отмена/повтор сбрасывают привязку к файлу, чтобы запись не затронула другой документ.

`tests/native_save_smoke.py` проверяет реальную запись, повторную запись и чтение FileSystemFileHandle в браузерном файловом хранилище; системный диалог выбора файла в тесте заменён программным выбором. Ручная проверка системного диалога в конкретном браузере и просмотрщике остаётся необходимой.


Карточка скрыта при запуске. Одиночный щелчок выбирает узел, не открывая её. F3 и кнопка с курсивной «i» переключают видимость карточки выбранного узла. Двойной щелчок по листу открывает её. Если карточка уже открыта, выбор другого узла обновляет её содержимое. Двойной щелчок по группе по-прежнему сворачивает/раскрывает потомков.

## Статус узла (0.1.11)

В карточке каждого узла доступен список «Статус»: «Не задан», «Запланировано», «В процессе», «Готово». Выберите значение и нажмите «Применить». Пустой статус ничего не добавляет на карту; остальные показывают перед названием календарь, незавершённый круг или тёмно-зелёную галочку. У значков есть подсказки с названием статуса.

Поле `status` хранится в узле JSON (`""`, `"planned"`, `"in-progress"`, `"done"`), восстанавливается из локального хранилища и поддерживает отмену/повтор. Старые карты без поля получают пустое значение; новые узлы не наследуют статус родителя. «Не задан» убирает значок.

Проверка: `python3 tests/status_smoke.py`.

## Добавление и удаление с клавиатуры (0.1.12)

Рядом с «+» находится кнопка «−» для удаления выбранного узла со всеми потомками. Клавиши `+` и `Insert` добавляют дочерний узел, `-` и `Delete` удаляют выбранную ветку. Все способы удаления требуют подтверждения; отмена сохраняет карту без изменений. Корневой узел удалить нельзя. Добавление не требует подтверждения; диалог названия открывается как прежде.

В полях ввода, списках и открытых диалогах эти команды не действуют; удержание клавиши не повторяет команду. F2/F3 продолжают работать. Проверка: `python3 tests/edit_keys_smoke.py`.

## Смена родителя (0.1.14)

Выберите некорневой узел и нажмите кнопку «Сменить родителя» на панели рядом с добавлением/удалением. После сообщения «Выберите нового родителя» щёлкните по видимому узлу карты. Вся ветка будет переподчинена ему, сохранит заметки/статусы и расположится с нужной стороны. Свёрнутый новый родитель раскроется.

Нельзя переподчинить корень, привязать узел к самому себе или своему потомку. Ошибочный выбор оставляет режим активным. Escape, «Отмена» или повторное нажатие кнопки отменяет выбор. Другие действия панели сначала отменяют режим. Операция поддерживает отмену/повтор и сохраняется в JSON и последней локальной карте.

Проверка: `python3 tests/reparent_smoke.py`.

## Плавающая панель (0.1.15)

Инструменты расположены вертикально в порядке: карточка, добавить, удалить, сменить родителя, отменить, повторить. По умолчанию панель находится у правого края карты. Перетаскивайте её за ручку с точками сверху; при фокусе на ручке стрелки перемещают панель. Положение сохраняется отдельно от документа в этом браузере, подстраивается под доступный размер поля и не влияет на координаты узлов или историю карты.

Проверка: `python3 tests/toolbar_smoke.py`.
